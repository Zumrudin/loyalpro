🔌Подключение YClients
💳Карта лояльности YClients
Выберите тип карты лояльности из YClients. Все начисления кэшбэка будут идти на карты этого типа. Webhook finances_operation отслеживает оплаты и автоматически начисляет кэшбэк.
🔔Webhook URL
Вставьте этот URL в YClients → Настройки → Интеграции → Webhook.
Включите события: record, client, finances_operation.
🍪Куки браузера YClients
Используются для разового импорта истории карт. Как получить: войдите на yclients.com в браузере → F12 → Network → любой запрос → Request Headers → скопируйте строку Cookie: целиком.
Куки действуют ~30 дней
📋Импорт CSV транзакций
Выгрузите отчёты из YClients: Лояльность → Транзакции → Экспорт XLS, затем откройте в Excel и сохраните как CSV UTF-8.
Загружайте каждый тип файла отдельно. Дубли пропускаются автоматически.
📥Разовый импорт истории карт
Запустите один раз при внедрении — загрузит полную историю транзакций по картам YClients для всех клиентов. Дальнейшие операции фиксируются автоматически через webhook.

Новая программа
Условия зачисления (событие: состоявшийся визит)
Без условий программа срабатывает на любой состоявшийся визит. Внутри одного условия значения объединяются через ИЛИ.
Объединять условия:
И ИЛИ
Цепочка касаний
Т+N дней после визита, время — московское. «Мила пишет сама» — текст задаётся смыслом (что узнать или предложить). «Готовый текст» — Мила отправит написанное дословно, но по-прежнему решает, уместно ли касание вообще.
Проверка выборки
Сухой прогон: кто попал бы в программу, если бы она работала последние N дней. Ничего не сохраняется и никому не отправляется.

Новое правило
Условия визита
Без условий сохранить нельзя: без них напоминание уйдёт после ЛЮБОГО визита. Внутри одного условия значения объединяются через ИЛИ.
Объединять условия:
И ИЛИ
Текст
📋 Готовый текст ✍️ Мила пишет сама
Подстановки: {first_name} {name} {услуга} {мастер} {дней} {бонусы} {баланс} {салон}
Кап ограничивает только просроченных: строки, которым ещё не подошла естественная дата, встают на неё и в кап не считаются. Темп считается по всем плановым отправкам салона, включая «Заботу» и автоуведомления, поэтому при нескольких правилах паузу задаёт то правило, чьё сообщение уходит сейчас. 0 — без паузы.
Догон по базе
Задайте период и нажмите «Показать выборку»
Тестовая отправка
Правило прогоняется тем же воркером, что и в бою: текст (в режиме «Мила пишет сама» — живой LLM-проход) и ступень бонусов считаются по-настоящему. Сообщение реально уйдёт на указанный номер. Анти-повтор и лимит «одно сообщение в день» на тест не действуют, чёрный список и выключенный агент — действуют.
Укажите номер и нажмите «Отправить тест»
