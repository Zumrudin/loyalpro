Интеграция YClients
🍪 Куки браузера YClients (для разового импорта истории карт)
Как получить: войдите на yclients.com в браузере → F12 → Network → любой запрос → Request Headers → скопируйте строку Cookie: целиком.
Куки действуют ~30 дней. После импорта истории их можно не обновлять.
Карта лояльности YClients
Выберите тип карты лояльности из YClients. Все начисления кэшбэка будут идти на карты этого типа. Webhook finances_operation отслеживает оплаты и автоматически начисляет кэшбэк.
Webhook URL
Вставьте в YClients → Настройки → Интеграции → Webhook
События: record, client, finances_operation

📊 Импорт истории транзакций из CSV (YClients)
Выгрузите отчёты из YClients: Лояльность → Транзакции → Экспорт XLS, затем откройте в Excel и сохраните как CSV UTF-8.
Загружайте каждый тип файла отдельно: пополнения, списания с карты, ручные списания. Дубли пропускаются автоматически.
📥 Разовый импорт истории карт лояльности
Запустите один раз при внедрении — загрузит историю транзакций по картам YClients для всех клиентов. После завершения вся история будет в базе. Дальнейшие операции фиксируются автоматически через webhook.
