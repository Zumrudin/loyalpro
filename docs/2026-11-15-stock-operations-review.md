# Складские операции: реализация и ревью

Дата: 15.11.2026. Основной агент провёл ревью изменений Luna, Terra и Sol,
а также интеграцию и проверку расчётов. План:
`superpowers/plans/2026-11-15-stock-operations-layout.md`.

## Что изменено

- `frontend/js/pages/stock-docs.js`: построчная таблица из 13 колонок,
  фильтры, пагинация, история, меню существующих форм, скачивание XLSX.
- `frontend/js/pages/stock.js`, `frontend/index.html`, `frontend/css/stock.css`:
  интеграция вкладки, очистка контекста, версии ресурсов, desktop/mobile и темы.
- `backend/services/stock/operations.js`, `query.js`, `backend/routes/stock.js`:
  отдельный API движений; старый API документов сохранён.
- `backend/services/stock/operation-values.js`: остаток по полной истории
  и историческая стоимость. Для неизвестных единиц/базы — null.
- `backend/services/stock/operations-export.js`: XLSX всей выборки с одним
  repeatable-read снимком и числовыми ячейками.
- `backend/services/stock/history.js`, `backend/migrations.js`: отдельный
  аудит документов и движений, метаданные известных старых событий.
- Добавлены четыре Jest-файла и сценарии `stock-operations-e2e.js`,
  `stock-operations-browser.js`.

## Исправлено на ревью

- Цена продажи не используется как себестоимость; будущие приходы и текущая
  цена каталога не подставляются в прошлую продажу.
- Остаток не зависит от фильтра и текущей страницы; исключённые/отменённые
  движения не меняют его. Неизвестные единицы в учитываемой истории не
  выдают предположительное число за достоверное.
- Экспорт использует применённую выборку, пагинация сохраняет фильтры.
  Ошибка загрузки убирает старые строки и блокирует выгрузку.
- Отдельные счётчики запросов для таблицы и модальных окон; при повторном
  входе очищаются старые услуги, строки и фильтры.
- Поиск работает по локальному и внешнему номеру; для перемещения контрагентом
  является противоположный склад. Удалённое зеркальное движение помечено.
- Продажа с неизвестной суммой имеет неизвестный статус оплаты, не «Не
  применимо». Статусы оплаты отделены от статусов документа.
- В истории нет свободного текста комментариев: фиксируется только факт
  изменения. Повтор без изменений не создаёт события. Старые даты явно
  помечены как известные метаданные, без выдуманного состояния в прошлом.
- Миграция истории выполняется одним атомарным SQL-запросом, ошибка не
  скрывается. Установка повторяема, запись аудита откатывается вместе с
  бизнес-операцией.
- Таблица проверена визуально по скриншотам; ширина товара увеличена,
  заголовки и ссылки оформлены по образцу, прокрутка ограничена таблицей.

## Безопасность

Роли owner/admin и существующие проверки форм сохранены. salon_id берётся
из JWT, все соединения tenant-owned таблиц ограничены салоном. Поиск
параметризован, символы LIKE экранированы. Телефон участвует в поиске, но
не возвращается новым API. UI экранирует текст, Excel пишет только
примитивные значения, формульные строки нейтрализуются. Внешних вызовов и
новых финансовых/бонусных эффектов нет.

## Выпуск и ограничения

Не выполнялись: перезапуск/развёртывание сервисов, установка миграции в
постоянную схему, проверка с реальными пациентами, внешняя синхронизация,
нагрузочный прогон на производственной базе. Мобильное приложение не
изменялось; его lint не запускался.

При выпуске сначала установить добавочную миграцию истории (таблица,
индекс, две функции и два триггера), затем новый сервер/ресурсы. Установка
триггеров требует короткой блокировки складских таблиц; backfill отсутствует.
Контроль: наличие обоих триггеров и индекса, открытие `/operations` и
истории под owner/admin. Откат кода сохраняет таблицу аудита; удаления
истории для отката не требуется.

Остаток — реконструкция по текущей сохранённой истории, а не неизменяемый
снимок прошлого. До входящего снимка достоверного остатка нет. Старые
не сохранённые изменения восстановить нельзя. История показывает последние
200 событий с явным указанием ограничения. Черновики без движений доступны
через существующие документы/инвентаризацию, не создают фиктивных товарных
строк. Чужие незакоммиченные изменения оставлены на месте.
