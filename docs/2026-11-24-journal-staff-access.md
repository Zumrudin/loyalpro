# Доступ сотрудников к журналу — 24.11.2026

Изменение выложено на dev и prod 24.11.2026 в рамках ранее разрешённой выкладки на оба стенда. Перезапущен только процесс loyalpro каждого стенда. Изменение доступа не требует миграции БД.

| Возможность | owner | admin | admin_cashier | specialist |
|---|---|---|---|---|
| День, неделя, месяц, сводка дня | Да | Да | Да | Да |
| Карточка записи и история изменений | Да | Да | Да | Да, только просмотр |
| Телефоны в ответах API журнала | Да | Да | Да | Скрыты |
| Создание и изменение записей, оплаты, отправка пакетов | Да | Да | Да | Нет |
| Клиентские инструменты журнала | Да | Да | Да | Нет |
| Изменение графика сотрудников, список изменений и восстановление | Да | Да | Нет | Нет |
| Проверка неопределённых операций владельцем | Да | Нет | Нет | Нет |

Владелец сохраняет прежние административные возможности. Роль и салон берутся из авторизованной сессии; значения в query/body не расширяют доступ. Неизвестные роли отклоняются.

Специалисту разрешены только GET `/api/journal/day`, `/day-summary`, `/week`, `/month`, `/records/:id` и `/records/:id/history` под тем же префиксом. Из ответов рекурсивно удаляются поля телефонов; телефоны в комментариях, именах, истории и текстах ошибок маскируются. Общие DTO не изменяются. Ответы содержат `capabilities`: `canEdit`, `canViewPhones`, `canUseClientTools`, `canManageSchedule`. Интерфейс специалиста показывает карточку для чтения без переходов к клиентским инструментам и действий изменения.

Ограничение телефонов относится к API журнала. Права существующих модулей домашнего ухода, портфолио и других разделов не пересматривались; доступные специалисту телефоны вне журнала этим изменением не скрываются.

На странице «Рабочий день» кассиру разрешены просмотр сводки записей и списка папок, изменение отметки `prepared` у клиентской или предварительной папки. Эта возможность не открывает весь `/api/clients`: архивирование, регистрация номера и дополнительные поля в таком запросе кассиру запрещены. Остальные существующие права кассира сохраняются.

Живые внешние операции и развёртывание не выполнялись. Этот запуск не является подтверждением браузерной проверки.
