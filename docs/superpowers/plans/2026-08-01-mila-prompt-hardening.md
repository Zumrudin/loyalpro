# Mila Prompt Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Закрыть найденные аудитом слабые места промпта Милы (безопасность, честность, тон) и ввести трёхуровневые «медицинские границы» для вопросов о показаниях/противопоказаниях.

**Architecture:** Почти все правки — в чистой функции `buildSystemPrompt` (`backend/services/agent/system-prompt.js`), защищённой тестами `backend/agent-system-prompt.test.js` (каждая правка промпта = тест-страж, порядок TDD). Три код-правки: санитизация имени клиента (`sanitize.js`), окно присутствия администратора (новый чистый модуль `admin-hours.js`, используется оркестратором для промпта и диспетчером для детерминированной фразы), анти-абьюз лимит записей на чужие номера (новый модуль `third-party-limit.js`, точка врезки — `tools/create-booking.js`, `book_chain` наследует автоматически, т.к. зовёт `createBk.run`).

**Tech Stack:** Node.js, jest (`cd backend && npx jest <pattern>`). Ветка `feat/chat-v2`. После выката — рестарт дева `PORT=3001 pm2 restart loyalpro --update-env` + `curl :3001`.

**Non-goals (сознательно отложено):**
- Иерархия правил / снятие капса (риск регрессов у слабых моделей несоразмерен выигрышу; при следующем большом рефакторинге промпта).
- Разбивка ответа на серию коротких сообщений (фича уровня dispatcher/send, требует живого E2E — отдельная задача).
- Наполнение базы знаний медицинскими статьями — контент утверждает врач; здесь только чек-лист (Task 8).

```js
// Пусто/мусор → null: агент работает по ветке «имени не знаем» и вежливо спросит.
function sanitizeName(value, maxWords = 3, maxLen = 40) {
  const words = [];
  for (const w of sanitizeLine(value, 200).split(' ')) {
    if (!/^[\p{L}][\p{L}.'-]*$/u.test(w)) break;
    words.push(w);
    if (words.length >= maxWords) break;
  }
  return words.join(' ').slice(0, maxLen).trim() || null;
}
```
