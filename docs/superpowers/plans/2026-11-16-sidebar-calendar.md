# Календарь и сворачиваемая панель

Реализовано по запросу владельца от 16.11.2026. Размещение — под брендом и названием клиники, перед меню. Десктопное оформление Ivory: панель 280 px, свёрнутая полоса 64 px с логотипом и иконками. Группы открываются рядом с полосой; Escape закрывает меню и возвращает фокус. На узком экране календарь находится в существующем мобильном drawer.

## Контракт

- Источник выбранной даты — `jrDate`; сегодняшняя дата — существующий `jrToday` (Москва).
- Календарь показывает шесть недель, начиная с понедельника, включая дни соседних месяцев.
- Перелистывание месяца не вызывает API. Выбор дня открывает журнал или обновляет текущий журнал ровно один раз; мобильное меню закрывается.
- Обычная загрузка журнала возвращает календарь к выбранному месяцу. Фоновое обновление той же даты сохраняет просматриваемый месяц.
- Календарь доступен только ролям, которым существующее меню разрешает журнал. Иконки и группы используют те же DOM-пункты и проверки ролей.
- В localStorage сохраняется только флаг `loyalpro.ivorySidebarCollapsed`; ошибки доступа к storage не мешают работе. Даты и данные пациентов не сохраняются.
- API, БД и интеграционные действия не меняются. Классический десктопный вид сохраняет прежнюю навигацию.
