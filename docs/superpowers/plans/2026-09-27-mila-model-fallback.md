## Security/privacy review

GET/PUT/ack защищены JWT + owner/admin, tenant/user не принимаются из тела.
Все новые запросы состояния имеют salon_id; подтверждения дополнительно user_id.
Мост не получает доступ к приложению, модели не выполняют CRM-инструменты.
Selector ограничен enum и подписан; секреты/диалоги не входят в уведомления,
ошибки API или CLI. Поздний сбой не перезаписывает ручной выбор (revision CAS).
Повторяется только LLM-вызов, не оркестрация инструментов и отправка сообщений.
При полном отказе состояние честно показывает error, успешная работа не имитируется.
