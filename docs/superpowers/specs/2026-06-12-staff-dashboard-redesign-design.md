# Редизайн дашборда специалиста — пастельный дружелюбный UI

**Дата:** 2026-06-12
**Статус:** утверждено пользователем
**Затрагивает:** `frontend/js/pages/staff-dashboard.js`, `frontend/css/features.css`, минимально `backend/routes/api.js` (поле `staffAvatar`)

## Проблема

Текущий дашборд специалиста — серые карточки `.sc` (белый фон, тонкая рамка, мелкий
серый лейбл + цифра), плоский одноцветный canvas-бар-чарт, без иконок и анимаций.
Пользователь просит дружелюбный, живой интерфейс с понятной графикой и анимацией.
Все данные и цифры сохраняются как есть.

## Решения пользователя (зафиксировано в диалоге)

1. Стиль: **C — мягкий пастельный** (бьюти-вайб)
2. График: **A — плавная градиентная область** (как Apple Health), hover-тултипы, анимация отрисовки
3. Анимации: **A — полный набор** (count-up, каскад, кольца, hover)
4. Hero: **A — приветствие** с аватаром и сводкой по времени суток
5. Топ-5: **A — рейтинг с прогресс-барами** + сортировка по колонкам Кол-во/Выручка
6. Реализация: **A — SVG + чистый CSS/JS**, ноль зависимостей

## 1. Палитра

Новые CSS-переменные (блок `sd-*` в `features.css`), по одной паре на метрику:

| Метрика        | Пастельный фон | Акцент    |
|----------------|----------------|-----------|
| Выручка        | `#e6f7f1`      | `#0fa97e` |
| Визиты         | `#e8f1fd`      | `#3b82f6` |
| Не пришли      | `#fdf0e6`      | `#e8833a` |
| Средний чек    | `#f0ecfd`      | `#7c5cf0` |
| Первичные      | `#fdecf2`      | `#e0508a` |
| Возвращаемость | `#e4f6f8`      | `#0ea5b7` |
| Перезапись     | `#eff8e6`      | `#6aa832` |
| Товары         | `#fdf4e2`      | `#d99114` |
| Загрузка       | `#f5ebfa`      | `#a855d8` |

Карточки: пастельный фон вместо белого, **без рамок**, скругление 16px,
мягкая тень усиливается при hover (+подъём 2px). Иконка метрики (эмодзи)
в белом круге слева от лейбла. Цифра — цветом акцента метрики.

**Тёмная тема:** переопределение тех же переменных в `[data-theme="dark"]` —
тёмные приглушённые версии оттенков (мятный → `#11261f` и т.п.), акценты ярче.

## 2. Структура страницы (сверху вниз)

1. **Hero-блок** — градиентная полоса (мятный → лавандовый, 135°), скругление 20px:
   - Аватар мастера 56px круглый с белой обводкой (`staff_members.avatar_url`
     через новое поле API `staffAvatar`); fallback — инициалы на цветном круге
   - Приветствие по времени суток (МСК), имя во всех вариантах: «Доброе утро, {Имя}! ☀️»
     (<12:00), «Добрый день, {Имя}! ✨» (12–18), «Добрый вечер, {Имя}! 🌙» (>18).
     Имя — первое слово `staffName`
   - Сводка: «За период: 24 визита на ₽218 000» (из `periodRecords` + `periodRevenue`)
   - Справа мелко: диапазон дат
2. **Переключатель периода** — сегментный контрол со скользящей «пилюлей»
   (Сегодня / Неделя / Месяц), логика периодов не меняется
3. **Ряд 1:** grid 3 колонки. Карточка Выручки — span 2 ячейки, рядом Визиты;
   вторая строка grid: Не пришли + Средний чек + Первичные
4. **Ряд 2:** grid 4 колонки: Возвращаемость, Перезапись, Товары, Загрузка.
   На мобильной ширине (<720px) оба ряда перестраиваются в 2 колонки,
   выручка — на всю ширину
5. **График выручки** (SVG-область)
6. **Топ-5 услуг** с барами и сортировкой

## 3. Карточки

**Выручка (главная):** иконка ₽ в белом круге, цифра 32px count-up,
разбивка Услуги/Косметика/Абонементы — каждая строка с цветной мини-точкой
и тонким мини-баром (доля от общей выручки).

**Обычные (Визиты 📅, Не пришли ✖️, Средний чек 💳, Первичные 🌱):**
иконка в белом круге, цифра 26px count-up.

**Процентные (Возвращаемость, Перезапись, Загрузка):** SVG прогресс-кольцо
64px, заполнение анимировано от 0 до значения, цифра внутри кольца.
Подписи-пояснения сохраняются. `null` → «—» без кольца (пустое серое кольцо).

**Товары** — не процент: обычная карточка «3 шт · ₽29 970».

## 4. График выручки (SVG)

- Сглаженная кривая catmull-rom → cubic bezier, линия 2.5px `#0fa97e`,
  под ней вертикальный градиент от `rgba(15,169,126,.25)` до прозрачного
- Появление: stroke-dashoffset слева направо, затем opacity заливки
- Hover: вертикальная пунктирная направляющая + точка на кривой +
  HTML-тултип «5 июн · ₽58 600», не выходит за края контейнера
- Ось X: прореженные подписи дат (как сейчас), высота 200px
- 1 точка данных (период «Сегодня») → вместо графика крупная плашка
  «₽58 600 за сегодня»
- Адаптивность через viewBox; resize не требует перерисовки вручную

## 5. Топ-5 услуг

- Строка: место (1–5) · название · пастельный бар · кол-во · выручка
- Длина бара пропорциональна доле услуги в выручке топ-5, анимация «вырастания»
- Лидер: 👑 рядом с номером, бар чуть насыщеннее
- **Сортировка:** клик по заголовкам «Кол-во» / «Выручка», стрелка ↑↓,
  дефолт — выручка по убыванию. Места и бары пересчитываются под текущий
  порядок (место = позиция в текущей сортировке)

## 6. Анимации

Все ≤ 0.6с, `ease-out`:
- Каскад карточек снизу-вверх, задержка 60мс между карточками
- Count-up цифр через requestAnimationFrame, 600мс
- Кольца и бары: заполнение 700мс после появления карточки
- `@media (prefers-reduced-motion: reduce)` → все анимации отключены

## 7. Технические границы

- **JS:** переписывается рендер в `frontend/js/pages/staff-dashboard.js`
  (canvas-чарт `_sdDrawChart` заменяется на SVG-генератор)
- **CSS:** новый блок `sd-*` в `frontend/css/features.css`
- **Backend:** в ответ `/api/analytics/staff-dashboard` добавляется
  `stats.staffAvatar` (из `staff_members.avatar_url`); больше API не трогаем
- Главный дашборд и остальные страницы **не затрагиваются**
- Никаких внешних библиотек

## Критерии приёмки

1. Все 10 метрик показывают те же цифры, что и до редизайна
2. Переключение периодов работает; «пилюля» скользит
3. График: сглаженная область, hover-тултип с датой и суммой
4. Топ-5: бары, корона у лидера, сортировка по двум колонкам
5. Анимации идут при загрузке и отключаются при prefers-reduced-motion
6. Тёмная тема выглядит согласованно (без «грязных» пастелей)
7. unlinked-плашка (профиль не привязан) сохраняет работоспособность
8. Мобильная ширина: карточки перестраиваются в 1–2 колонки без горизонтального скролла
