# База знаний Милы: импорт частых вопросов пациентов

Дата: 09.10.2026. Источник: `docs/2026-10-08-patient-questions-by-service.md`.

## Решение

- Наблюдения из разбора переписок добавляются короткими самостоятельными FAQ-абзацами в существующие опубликованные статьи PERI CLINIC.
- Новые статьи и услуги не создаются. Сопоставление выполняется по заголовку статьи внутри заданного `salon_id`; неоднозначность останавливает весь импорт до записи.
- Конкретные денежные суммы в FAQ запрещены тестом и проверкой импортера. Фактические цены продолжает добавлять `agent-rag` из YClients через существующие `kb_article_links`.
- Для статьи, связанной с услугой, `agent-rag` удаляет из найденных чанков старые строки с рублёвыми суммами перед сборкой контекста. Живая цена из YClients добавляется после этого отдельным блоком. Несервисные статьи не фильтруются.
- При явном вопросе о цене (`цена`, `стоимость`, `сколько стоит`, `почём`, `прайс`) статические рублёвые суммы удаляются из всех найденных статей, даже если исторические `kb_article_links` не заполнены. Актуальные цены в боевом catalog-mode уже находятся в каталоге YClients системного промпта.
- Импорт идемпотентен по заголовку `## Частые вопросы пациентов по перепискам (обновлено 08.10.2026)`.
- Скрипт работает в dry-run по умолчанию. Запись в `loyalpro_test` требует `--commit`; production дополнительно требует точной комбинации `--db loyalpro --commit --allow-production` после явного подтверждения пользователя.
- После записи каждая статья синхронно переэмбеддится, а состав чанков и наличие эмбеддингов проверяются.

## Запуск

Из `backend/`:

```bash
node scripts/kb-import-patient-questions.js --db loyalpro_test
node scripts/kb-import-patient-questions.js --db loyalpro_test --commit
# Только после явного разрешения на production:
node scripts/kb-import-patient-questions.js --db loyalpro --commit --allow-production
```

Для одного или нескольких разделов: `--only laser,botulinum`. Другой салон задаётся только явно: `--salon <id>`.
