# Визуальный drag-редактор координат медсправки — Design Spec

**Дата:** 2026-06-17
**Связано:** [план генерации PDF](../plans/2026-06-17-medical-cert-pdf.md), [спека генерации](2026-06-17-medical-cert-pdf-design.md)

## Цель

Дать администратору клиники визуально откалибровать карту координат полей бланка КНД 1151156: видеть реальный пустой бланк, перетаскивать поля мышью на нужные клетки, точно доводить позицию стрелками клавиатуры и править остальные параметры поля (шаг ячеек, размер шрифта, ширина) в боковой панели — вместо ручного редактирования JSON «вслепую».

Решает задачу калибровки (Task 10 исходного плана), которую невозможно выполнить через текстовый JSON-редактор за разумное время.

## Контекст / ограничения

- Чисто **фронтенд**-фича. Бэкенд **не меняется**.
- Ванильный JS SPA, статика отдаётся бэкендом (правки живут на reload, без сборки).
- Проект уже грузит сторонние библиотеки с CDN jsdelivr (`chart.js`, `canvas-confetti`) и лениво подключает `html2pdf` динамическим `<script>` в [staff.js](../../../frontend/js/pages/staff.js#L373) — `pdf.js` подключаем тем же способом.
- Есть паттерн полноэкранной модалки (`staff-profile-modal`: `position:fixed;inset:0;z-index:1000;background:rgba(0,0,0,.45)`) и хелперы `api()`, `notify(msg,type)` (тип ошибки — `'err'`), `esc()`, `escAttr()`.

## Эндпоинты

- `GET /api/medical-cert/template/coords` → карта координат `{ version, pageSize:{width,height}, fields:{...} }`.
- `PUT /api/medical-cert/template/coords` (body = вся карта) → `{ ok:true }`.
- **`GET /api/medical-cert/template/blank`** (добавлен) → сырой PDF активного бланка (`application/pdf`), same-origin прокси к S3.

Формат поля карты (из дефолтной карты): `{ page, type:'cells'|'text'|'checkbox', x, y, step?, max?, width?, lineHeight?, fontSize?, align?, anchorRight? }`.

### Доставка бланка и pdf.js (важно — CSP)

Приложение отдаёт строгий CSP (`connect-src 'self'`, helmet в `server.js`). Браузер **не может** делать `fetch`/XHR на чужой origin, поэтому pdf.js **нельзя** скармливать presigned-S3-URL напрямую (а у бакета Yandex ещё и нет CORS-заголовков). Решение — всё с того же origin:

- Бланк грузится байтами через прокси `GET /api/medical-cert/template/blank` и передаётся в `pdfjsLib.getDocument({ data })` — pdf.js не делает сетевых запросов на чужой origin.
- `pdf.js` и его worker **вендорятся** в `frontend/js/vendor/pdfjs/` (`pdf.min.js`, `pdf.worker.min.js`, v3.11.174) и грузятся same-origin — без CDN/CSP-зависимостей и без ослабления CSP.
- `<img>`-превью S3 по-прежнему работают через `imgSrc` (CSP это разрешает), но для `connect-src` это не помогает — отсюда прокси.

## Архитектура

### Модуль 1 — `frontend/js/pages/medical-cert-coords-transform.js` (чистый, тестируемый)

Чистые функции преобразования координат PDF ↔ экран. Без DOM. Покрываются `node:test`.

- `ptToScreen(field, ctx)` → `{ left, top }` в px, где `ctx = { scale, pageHeightPt }`.
  - `left = field.x * scale`
  - `top = (pageHeightPt − field.y) * scale − (field.fontSize||11) * scale`
    (поправка на baseline: `drawText` в pdf-lib рисует от базовой линии вверх, маркер привязываем к ней).
- `screenToPt(left, top, fontSize, ctx)` → `{ x, y }` в pt, целые (округление), обратное к `ptToScreen`.
- Инвариант (тест): для целых `x,y` round-trip `screenToPt(ptToScreen(...)) === {x,y}`.
- `sampleFor(name, field)` → строка-образец для отрисовки следа поля (даты → `02.06.2009`, суммы → цифры, ФИО → `АГАФОНОВ` и т.п.; по умолчанию — имя поля). Чистая, тестируемая на нескольких ключах.

### Модуль 2 — `frontend/js/pages/medical-cert-coords-editor.js` (UI, ручная проверка)

Глобальные функции (вызываются из inline-`onclick`, как в остальном SPA):

- `mcOpenVisualEditor()` — точка входа:
  1. `GET /template`; если нет `url` → `notify('Сначала загрузите бланк','err')`, выход.
  2. `GET /template/coords` → рабочая копия карты в модульной переменной.
  3. Показать модалку, лениво подгрузить pdf.js (если ещё не загружен), затем `mcRenderAllPages()`.
  4. Ошибка загрузки pdf.js → `notify(...,'err')`, модалку закрыть (остаётся JSON-fallback).
- `mcRenderPage(pageIndex)` — рендер страницы бланка в `<canvas>` через pdf.js с выбранным `scale` (подбираем так, чтобы ширина рендера ≈ 800px), затем построить слой маркеров для полей этой страницы поверх canvas.
- `mcRenderAllPages()` — рендер всех страниц документа (бланк 2-страничный, но рисуем столько, сколько в PDF).
- Маркер поля: абсолютный `div` с позицией из `ptToScreen`, внутри — отрисованный «след» (`sampleFor`) в `fontSize*scale`; для `cells` — `max` ячеек с шагом `step*scale`. Клик выделяет поле (подсветка + заполнение боковой панели). Перетаскивание мышью меняет `x,y` (через `screenToPt`). При фокусе на маркере стрелки клавиатуры двигают на ±1pt.
- Боковая панель: инпуты `x, y, step, fontSize, width, max, align, anchorRight` для выбранного поля; `input` → обновляет карту и перерисовывает маркер. `name`/`page` — read-only.
- Тумблер «Сетка»: накладывает координатную сетку (линии каждые 50pt с подписями) поверх canvas — вспомогательный ориентир.
- `mcSaveVisualCoords()` — `PUT /template/coords` рабочей картой → `notify('Координаты сохранены')`, закрыть модалку.
- `mcCloseVisualEditor()` — закрыть без сохранения (рабочая копия отбрасывается).

### UI-хост — правки в `frontend/index.html` и `frontend/js/pages/medical-cert.js`

- В блок «Шаблон бланка» добавить кнопку «Редактор координат (визуальный)» → `mcOpenVisualEditor()`. Существующую кнопку JSON-редактора подписать как fallback («Редактор JSON»).
- Добавить разметку модалки `#mc-visual-editor` (скрыта по умолчанию) по паттерну `staff-profile-modal`: шапка (Сохранить / Отмена / тумблер «Сетка»), слева скролл-контейнер `#mc-ve-pages` под canvas+маркеры, справа панель `#mc-ve-panel`.
- Подключить `<script src="js/pages/medical-cert-coords-transform.js">` и `<script src="js/pages/medical-cert-coords-editor.js">`.

## Поток данных

1. Открытие → загрузка бланка (presigned URL) + текущей карты.
2. pdf.js рендерит страницы; для каждого поля по `ptToScreen` ставится маркер с образцовым следом.
3. Пользователь тащит/доводит стрелками/правит панель → меняется рабочая копия карты, маркер перерисовывается.
4. «Сохранить» → `PUT /template/coords` → карта в БД обновлена; последующая генерация PDF использует новые координаты.

## Граничные случаи и обработка ошибок

- Нет активного бланка → ранний выход с `notify('...','err')`.
- pdf.js не загрузился (нет сети) → `notify('...','err')`, fallback остаётся (JSON-редактор).
- Поле без `page` → трактуем как `0`.
- `align:'right'`/`anchorRight` — маркер позиционируем по `x` (левый край); панель позволяет задать `anchorRight`. Точная правая привязка проверяется генерацией реального PDF.
- Координаты округляются до целых pt при сохранении.

## Тестирование

- **Юнит (`node:test`)** для `medical-cert-coords-transform.js`: round-trip `pt→px→pt`; корректность baseline-поправки на нескольких `fontSize`; `sampleFor` для ключевых полей.
- **Ручная/Playwright smoke**: кнопка открывает модалку, бланк рендерится в canvas, маркеры присутствуют, перетаскивание меняет значения в панели, «Сохранить» шлёт `PUT` (проверка по сети/в БД).
- Финальная фактическая калибровка против эталона «Агафонов 2025» — ручная (исходный Task 10), уже с помощью этого редактора.

## Вне скоупа (YAGNI)

- Добавление/удаление полей карты (набор полей фиксирован схемой бланка).
- Версионирование/история правок карты (есть версия шаблона).
- Snap-to-grid при перетаскивании (доводка стрелками покрывает точность; можно добавить позже).
- Серверные изменения.
