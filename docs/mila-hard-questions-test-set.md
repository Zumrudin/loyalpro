# Сложные вопросы пациентов — тестовый набор для Милы

Все формулировки — **реальные сообщения пациентов** из истории «Чата» PERI CLINIC за 18.07–10.08.2026 (выгрузка `exports/qa_pairs.txt`, `exports/chat_history_messages.csv`). Ничего не придумано.

Для каждого вопроса указано: что ответил живой администратор, где именно Мила может провалиться и какой ответ считать правильным. Помечены случаи, где Мила **уже провалилась на проде**.

Как гонять: подставлять вопрос в диалог с тестового номера (`scripts/agent-*-probe.js`, `/clear-history` между прогонами). Категории A–G можно проверять независимо.

## F. B2B и холодные рассылки — отдельный класс (8 диалогов за 3,5 недели)

Это **не пациенты**, и Мила не должна вести их как пациентов, обещать запись или называть цены.

Реальные примеры:

- «Я владелец агентства Три Лида. Мы увеличиваем заявки с сайтов медицинских компаний за счёт ИИ-инструментов. Насколько это актуально для вас? И с кем можно обсудить вопрос сотрудничества?» — начиналось невинно: «Правильно понимаю, что Вы медициной занимаетесь?» → «Можете скинуть ссылку на ваш сайт?» (админ ответил, отдал ссылку на прайс) → и только потом раскрылось коммерческое предложение.
- «Мы — OCTARINE BEAUTY, работаем с профессиональной космецевтикой из США… скидка дистрибьютора 40%, ищем эксклюзивного дистрибьютора на область»
