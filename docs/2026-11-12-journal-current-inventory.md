5. Меняется: при создании — клиент, мастер, дата, время, услуги (кол-во/цена/скидка/итог), комментарий; потом — статус, строки услуг, перенос, отмена, оплата. Длительность = сумма услуг, не редактируется. Комментарий в карточке readonly.
6. API: 24 обработчика `/api/journal`, owner/admin; 3 — owner. Старые `POST /create|move|cancel|confirm` UI не вызывает.
7. Фон: крон зеркала (10 мин / ночь +120), справочники и графики (30 мин), воркер `journal_outbox` (2 с), ручной dispatch.
8. Оплата наличными/картой выключена `JOURNAL_ACCOUNT_PAYMENTS_ENABLED` (дефолт false); бонусы работают.
9. Нет: drag-and-drop, групповых записей, повторяющихся, истории изменений, печати, колонок ресурсов, записи без услуги, правки комментария, удаления записи, смены клиента, уведомлений клиенту (`send_sms:false` всегда), телефона в карточке, цвета/меток, недели/месяца.

## 4. Фон
- Крон при `JOURNAL_LOCAL_FIRST` (SRV:379-410): `mirror-near` */10 (вчера…+14), `mirror-far` 03:20 (…+120), `reference` */30 (staff, services, resources, accounts + графики до +60), прогрев при старте.
- Воркер outbox (outbox-worker.js): тик 2 с, до 20 пакетов; статусы `queued|running|done|failed|cancelled`; шаги `create, move, edit, confirm, cancel, pay, remove_payment` (sessions.js:106-120), порядок create → move → edit → статус → оплаты → удаления; состояния шага `pending|done|failed|uncertain`; аренда только `released_at`, один `running` на салон, пакеты записи по id, дочерние ждут create; повторы 5/30/120/600/600 с, 6 попыток; `running` >15 мин возвращается; retry перегенерирует opId; dismiss отменяет дочерние.
- Dispatch: выпускает пакеты записей по периоду (≤366 дней), ставит `released_at`/`release_id`, `finance_operations` → `sending`; кнопка «Отправить в YClients (N)».
