# Шаблоны Chatpush/YClients для салона 1 (последние 120 дней)

Выгружено скриптом `backend/scripts/chatpush-notifications-harvest.js`. Шаблоны сгруппированы по тексту с числами, замененными на `#`; в блоке показан реальный пример текста.

Порядок работы с этим файлом: он ведётся ВРУЧНУЮ. Скрипт пишет сырую выгрузку вне репозитория (по умолчанию `/tmp/chatpush-templates-raw.md`; во `frontend/` нельзя: каталог раздаётся сервером статикой без авторизации, а в сырой выгрузке есть имена пациентов из касаний «Заботы» и реплик Милы) и сюда не пишет; из сырого файла сюда переносят только служебные уведомления YClients/Chatpush.

Параметры выгрузки: `--salon=1 --days=120 --min=2` (порог 2, чтобы попал редкий автоответ на низкую оценку). Блоки, не относящиеся к уведомлениям YClients/Chatpush (касания «Заботы» с именами пациентов, реплики Милы, рассылки), удалены вручную. Разделы с картинками обновлены по перезапуску скрипта 14.10.2026 с тем же окном.
