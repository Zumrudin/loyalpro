Очисти историю переписки с AI-агентом.

Ключ диалога: `$ARGUMENTS`. Если аргументов нет — используй тестовый номер владельца **79200255591**, салон 1.

Шаги:

1. Сначала dry-run, чтобы показать, что именно удаляется:
   `cd /root/loyalpro/backend && node scripts/clear-dialog.js <ключ>`
2. Покажи пользователю сводку (сколько сообщений, какие последние реплики).
3. Затем удали: `cd /root/loyalpro/backend && node scripts/clear-dialog.js <ключ> --apply`
4. Отчитайся: сколько сообщений и строк состояния удалено.

Важно:
- Скрипт чистит `chatpush_messages` + состояние `agent_dialogs` — после этого следующее входящее стартует диалог с чистого листа.
- В dev-БД лежит РЕАЛЬНЫЙ трафик PERI CLINIC (прод-инстанс мессенджера пишет в dev). Никогда не удаляй чужие номера без явного указания пользователя — только тот ключ, который назван.
- Если номер не назван и он не 79200255591 — переспроси, а не угадывай.
