# Бланк КНД 1151156

`blank.pdf` — чистый двухстраничный бланк, подготовленный 11.11.2026.
Заполненные значения удалены из структуры PDF вместе со слоем Adobe Fill & Sign;
сетка, подписи полей и штрихкоды сохранены. Данных пациента в файле нет.

`coords.json` — откалиброванная карта всех 50 полей, поддерживаемых
`routes/medical-cert.js`. Использовать только вместе с этим бланком:
координаты страницы 2 отличаются от страницы 1, шаг клетки — 14.1732283465 pt.
Маркер `_p2patch_v1` сохраняет ручную калибровку при запуске существующих миграций.

## Установка

Для выбранной клиники загрузить `blank.pdf` в разделе «Справки → Шаблон»,
затем сохранить содержимое `coords.json` через редактор JSON координат.
Те же операции доступны через авторизованные `POST /api/medical-cert/template`
и `PUT /api/medical-cert/template/coords`. После загрузки обязательно сохранить
эту карту: загрузчик первоначально копирует координаты предыдущего шаблона.
Установка в рабочую среду требует явного разрешения владельца.

Схема БД и код генератора не меняются. Шаблон и координаты хранятся в S3 и БД,
поэтому одного Git checkout для активации недостаточно. Перезапуск не нужен.
Перед заменой сохранить предыдущий бланк и карту; для отката загрузить их
как новую версию. Если прежде шаблона не было, откат — деактивация добавленной
версии с обязательным ограничением по `salon_id`.

## Проверка

Генерация с вымышленными данными плательщика и другого получателя проверена
визуально на обеих страницах. Проверены все 50 полей, перенос названия организации,
раздельные блоки дат, серия и номер документа, рубли и копейки.

Проверки ядра:

```sh
node --test backend/services/medical-cert-layout.test.js backend/services/medical-cert-pdf.test.js
```

Известное поведение генератора: PDF всегда сохраняет две страницы бланка,
в том числе при совпадении плательщика и пациента; в этом случае поля пациента
на второй странице остаются пустыми. Дата рядом с подписью внизу второй страницы
не входит в поддерживаемые поля генератора и заполняется вручную.
