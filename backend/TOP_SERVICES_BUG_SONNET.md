# Исправление: Топ услуг считает неправильно

## Проблема
На дашборде "Топ услуг" показывает количество **услуг в JSON**, а не количество **записей**.

## Пример
- Запись #1: [{Стрижка}, {Укладка}]  
- Запись #2: [{Стрижка}]

**Сейчас:** Стрижка = 2 ❌  
**Должно:** Стрижка = 2 (обе записи содержат Стрижку) ✓

## Исправление
**Файл:** `backend/routes/api.js` строка 112

**Заменить:**
```javascript
db.many(`SELECT svc->>'title' as service_name, COUNT(*) as cnt, ...`)
```

**На:**
```javascript
db.many(`SELECT svc->>'title' as service_name, COUNT(DISTINCT r.id) as cnt, ...`)
```

**Причина:** `jsonb_array_elements()` создает строку для каждого элемента массива. `COUNT(DISTINCT r.id)` считает уникальные записи.

## Проверка
После исправления на дашборде должны отобразиться **количество записей** (правильно), а не **количество услуг в JSON**.
